# Todo List

Простой список задач на React.

Функционал:

Возможность добавлять, удалять задачи и отмечать их как выполненные.

Установка и запуск:

Для начало необходимо установить в папку с проектом зависимости (node_modules) - npm i или npm install

Команда для запуска проекта - npm start
